# CodeFlow — Experimental Python Frontend Documentation

## 1. Overview & Positioning
CodeFlow provides an **experimental Python frontend** for a defined subset of Python syntax and semantics, translating supported Python programs into the existing CodeFlow compiler pipeline.

> [!NOTE]
> **Defensive Engineering & Academic Positioning**:
> CodeFlow is **not** a full CPython replacement or comprehensive Python compiler. Instead, it serves as an educational multi-language compiler pipeline demonstration, demonstrating how an alternative high-level language frontend can adapt into an existing intermediate representation (IR) and reuse 100% of the backend pipeline: Semantic Analysis, Three-Address Code (TAC), Control Flow Graph (CFG) analysis, multi-pass Optimization, Code Generation, and custom Stack Virtual Machine (VM) execution.

---

## 2. Compiler Pipeline Integration Architecture

```text
Python Source Code
       ↓
compiler.frontends.python.PythonFrontend
       ├── tokenize.tokenize → Python Lexical Tokens (serialized for IDE)
       └── ast.parse         → Python AST
                                   ↓
                       Subset Validation & AST Normalization
                                   ↓
                   CodeFlow AST (nodes.Program, etc.)
                                   ↓
       CodeFlow Semantic Analysis (Symbol Table, Scope & Type Inference)
                                   ↓
       CodeFlow Intermediate Code Generation (Three-Address Code)
                                   ↓
       CodeFlow Basic Block Partitioning (Leader Analysis)
                                   ↓
       CodeFlow Control Flow Graph (Directed Graph & Edge Classification)
                                   ↓
       CodeFlow Multi-Pass Optimizer (Constant Folding, DCE, Simplification)
                                   ↓
       CodeFlow Target Code Generator (Bytecode Emission)
                                   ↓
       CodeFlow Virtual Machine (Isolated Stack & Memory Execution Trace)
```

## 3. Supported Python Language Subset

| Category | Supported Constructs | Example |
| :--- | :--- | :--- |
| **Variables** | Single-variable assignments, augmented assignment (`+=`, `-=`) | `x = 10`, `y = 20.5`, `x += 1` |
| **Literals** | Integer, Float, Boolean | `42`, `3.14`, `True`, `False` |
| **Arithmetic** | Addition, Subtraction, Multiplication, Division, Modulo, Unary minus | `z = (x + y) * 2 - (10 / 2) % 3`, `-x` |
| **Comparisons** | `<`, `>`, `<=`, `>=`, `==`, `!=` | `if x >= 18:` |
| **Logical** | `and`, `or`, `not` | `flag and not (val < 10)` |
| **Conditionals**| `if condition:` and `else:` | `if x > 5:`<br>`    print(x)`<br>`else:`<br>`    print(0)` |
| **Loops** | `while condition:` | `while i < 5:`<br>`    print(i)`<br>`    i = i + 1` |
| **I/O** | `print(expression)` (single expression) | `print(result)` |

## 4. Unsupported Constructs (With Graceful Errors)

The frontend explicitly guards against unsupported Python features, rejecting them with line and column accurate errors:
- **Functions (`def`, `return`, lambdas)**
- **Classes & Object Orientation (`class`, methods, `self`)**
- **Imports (`import`, `from ... import`)**
- **Data Structures (lists `[...]`, dicts `{...}`, sets, tuples)**
- **Comprehensions & Generators (`[x for x in ...]`)**
- **Loops with Iterators (`for ... in ...`)** — `while` must be used
- **Exceptions (`try`, `except`, `finally`, `raise`)**
- **Chained Comparisons (`1 < x < 10`)** — `1 < x and x < 10` must be used
- **Dynamic Eval / Metaprogramming**

## 5. Lexical & AST Representation Details

### Lexical Information
Extracted directly via Python's standard `tokenize` module. Each token preserves:
- **Type**: `NAME`, `NUMBER`, `OP`, `NEWLINE`, `EOF`
- **Value**: Exact string slice (e.g. `'='`, `'x'`, `'10'`)
- **Location**: Line number and 1-indexed column number

### AST Translation
The AST normalizer traverses the `ast.Module` generated by `ast.parse`:
- First assignment of a variable in the scope converts to `nodes.VariableDeclaration`.
- Subsequent assignments convert to `nodes.Assignment`.
- Binary expressions (`ast.BinOp`, `ast.Compare`, `ast.BoolOp`) map directly to `nodes.BinaryExpression`.
- Control flow (`ast.If`, `ast.While`) maps into `nodes.IfStatement` and `nodes.WhileStatement` with `nodes.Block`.

---

## 6. Optimization & Target Execution

Because Python AST nodes are mapped into standard CodeFlow nodes:
1. **Constant Folding**: `a = 20 * 2` is folded into `40` by the optimizer and recorded in `optimization_steps`.
2. **Algebraic Simplification**: `x * 1 + 0` simplifies to `x`.
3. **Execution**: Emits `PUSH`, `LOAD`, `STORE`, `ADD`, `SUB`, `JMP_IF_FALSE`, `PRINT`, `HALT` target instructions, executing faithfully on the CodeFlow Stack VM. CPython is **never** used as an execution shortcut.
